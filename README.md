### 🎯 Why Use RobRun Companion?

Experiencing unexpected application crashes, micro-stutters, or inconsistent mouse movement during intense gaming sessions? Most players waste hours guessing what is wrong with their setup. **RobRun Companion** brings four essential engineering tools into one clean, user-friendly dashboard to give you clear answers in seconds.

No complicated menus. No background bloat. Just pure, accurate telemetry data about your PC and peripherals.

---

### 🚀 Core Modules & Features

#### 1. 🔍 System Diagnostics (Hardware & Environment Check)
Quickly verify if your Windows environment meets all stability requirements before launching heavy applications.
* **Instant Hardware Scan:** Checks CPU architecture, available RAM, GPU driver versions, and DirectX / Visual C++ runtime libraries.
* **Bottleneck Detection:** Identifies background resource hogs that consume memory and CPU cycles while you play.
* **Environment Health:** Ensures your OS configuration has no missing dependencies that commonly cause startup failures.

#### 2. 🖱️ Mouse Analyzer (Polling Rate & Input Consistency)
Your precision relies on hardware stability. Test how your mouse actually communicates with your PC.
* **Real-Time Polling Rate Test:** Measure true Hz frequency (125Hz, 500Hz, 1000Hz, up to 8000Hz) with live visual feedback.
* **Jitter & Consistency Check:** Detect signal drops, USB port instability, or sensor skipping.
* **Input Latency Insights:** Verify that your peripheral settings match your monitor refresh rate for smooth camera movement.

#### 3. 🩺 Crash Detective (Startup & Error Log Analyzer)
Stop staring at cryptic error codes when a game refuses to launch or closes unexpectedly.
* **Automated Log Parsing:** Scans local crash dumps and Windows Event Viewer logs to translate technical errors into plain English.
* **Root Cause Identification:** Pinpoints whether an issue is caused by graphics driver timeouts, insufficient virtual memory, or corrupted local cache.
* **Actionable Solutions:** Provides clear, step-by-step recommendations to fix startup crashes safely.

#### 4. 📊 Performance Recorder (Live Telemetry & Frame Time)
Track how your PC behaves under real load without heavy overlays slowing down your screen.
* **Lightweight Telemetry Logging:** Records CPU/GPU temperatures, clock speeds, RAM usage, and frame pacing over time.
* **Session Reports:** Review post-game graphs to see exactly when and why frame drops occurred.
* **Exportable Data:** Save clean diagnostic reports to share with tech support or community helpers.

### 🔒 Safety & Anti-Cheat Compatibility

**RobRun Companion** was built from the ground up with account safety as the #1 priority:
* **Zero Game Interaction:** The tool reads standard Windows API telemetry and hardware sensors only. It never touches game memory or executable files.
* **No System Modifications:** Unlike risky registry cleaners or aggressive system tools, this app leaves your Windows installation completely untouched.
* **Portable & Clean:** Runs smoothly on Windows 10 and Windows 11 with minimal resource footprint.
